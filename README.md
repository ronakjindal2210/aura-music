# ✦ AURA — Personalized Music Gift Experience ✦

A cozy, intimate, and dreamy music gift website featuring 20 aesthetic music worlds, interactive constellation universe, live audio atmosphere, and a persistent secret diary.

## ✨ Features

- **20 Unique Living Worlds**: Custom themes, animated atmospheres, and subtle audio reactivity.
- **✨ The Little Universe**: 20-star interactive constellation map with permanently displayed song names.
- **📖 Dear Diary ♡**: An intimate secret journal with real-time auto-saving and permanent `localStorage` persistence.
- **📱 Mobile-First Mini Player**: Expandable into a full-screen Now Playing screen with album art, track details, and seekbar.
- **💌 Personal Notes & Secret Letter**: Customized notes for every track, plus a 20/20 exploration reward.
- **☾ Tonight Mode**: Cozy ambient lighting and dimmed visuals for late-night listening.

## 🚀 How to Run Locally

```bash
python server.py 3000
```
Then visit `http://localhost:3000` in your browser.
